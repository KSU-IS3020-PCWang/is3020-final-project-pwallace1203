# AI Improvement Record

## Original Development

The orginal GoalMap was developed incrementaly by implementing one function at a time. It was created based off using a main menu interface, that allows user to create account, login, goal management and tracking. 

## AI Tools Used

ChatGPT(OpenAI)

## Improvements Requested

I asked AI for suggestions to improve the application's reliability, usability, and overall quality. My requests focused on:

Improving input validation.
Adding better exception handling.
Improving file reading and writing.
Enhancing the goal progress report.
Improving the user experience with clearer messages.
Reviewing the code for best practices and identifying potential bugs.
## Changes Accepted

I accepted AI recommendations that improved the application's reliability and user experience, including better input validation, stronger exception handling, improved CSV file processing, and a more informative goal progress report. These changes help prevent invalid input, reduce program crashes, and provide users with a clearer summary of their goals.

I verified each improvement by testing the application with both valid and invalid inputs, confirming that goals were saved and loaded correctly, and ensuring the updated progress report accurately reflected the current goal statuses.
## Changes Rejected or Revised

Some AI suggestions included adding more advanced features, such as stronger password security, more complex user account management, and additional interface enhancements. I chose not to include these suggestions because they exceeded the project requirements and would have significantly increased the application's complexity.

I also simplified several AI recommendations to better match the Python concepts covered in class. My goal was to keep the application readable, maintainable, and appropriate for an introductory Python course while still improving its functionality.

## What I Learned

The AI improvements showed me that I missed a lot of key features that could be very useful and beneficial to users. It gave me abetter understanding on how to improve the quality of my application. Input validation, exception handkinngm and structured file processing make the program more reliable.
